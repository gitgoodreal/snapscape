
# SnapScape

SnapScape is a responsive image discovery app where users will be able to search for visual inspiration across different topics. The interface uses an ocean-blue and warm-sand colour palette to create a calm, exploration-focused experience. I chose a split hero layout to make the introduction and search controls easy to find. I also included suggested category chips, a clear-search control, and an empty-state message to make the interface useful before search results are available.
